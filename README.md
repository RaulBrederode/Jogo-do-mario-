# jogoMario

## Descrição
Recriação do clássico jogo Mario, desenvolvida como parte da atividade de Front-End. O projeto inclui tela inicial, interface do jogador e mecânicas básicas do jogo.

## Objetivo
Colocar em prática os conceitos de Git e GitHub, organizando o projeto em um repositório real, com uso de branches (`main` e `dev`), commits e merge, seguindo uma estrutura próxima à utilizada em projetos de desenvolvimento de software profissionais.

## Tecnologias
- HTML
- CSS
- JavaScript

## Instalação
```bash
cd frontend
npm install
```

## Execução
```bash
npm run dev
```
